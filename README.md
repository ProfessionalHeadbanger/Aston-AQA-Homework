# Репозиторий для домашних заданий для курса AQA
В этом репозитории будут храниться все домашние задания в рамках курса по автоматизации тестирования.
Версия языка Java - 11 (Microsoft OpenJDK 11.0.29).

## Структура
Каждое домашнее задание будет помещено в отдельную ветку, озаглавленную номером задания, например, "Lesson_1".
